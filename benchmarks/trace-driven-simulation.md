# 真实增长驱动的双策略模拟：首个诊断

以已有固定 60% 轨迹提取 133 个相邻已配对普通调用的宿主上下文增长；跨摘要和无法配对请求的区间切断，剩余片段拼接成 134 次模拟调用，不是原始 140 次任务的完整重放。两条策略各自维护上下文、缓存和摘要记录，但消费完全相同的增长序列。

固定 60% 与研究用 `chooseSupportedCycle` 在本次模拟各摘要 3 次，估算费用均约 USD 1.5074；后者 0 次使用学习模型，全部回退固定 60%。这是冷启动回退结果，不是新策略战胜固定阈值。为检查分支确实独立，单元测试另用固定 50% 对照，验证压缩位置和费用产生变化；它不是本次主实验成绩。

假设：使用首次观测的宿主／provider token 差作为固定偏移；缓存始终存活、可复用上一请求的前缀且摘要后重建；摘要后保留 11%；摘要输入费用比例和输出量使用同一开发任务全部 11 条反馈的均值，普通输出为每次 300 token。相同费用假设同时提供给研究策略，因此它并非纯冷启动费用预测。11 条摘要输入都在约 21.4–21.7 万 token，而模拟在约 61 万 token 摘要，摘要模型属于**范围外外推**。不应因为总额接近旧实测就认定模型已校准：调用数、摘要轨迹及计费假设都不同。

增长片段拼接、摘要估算、缓存状态与不同策略下模型行为均为反事实假设；不包含任务质量，不证明任何真实策略省钱，也不替代已发生账单的逐项重放。下步应分解真实与模拟的普通费用差，增加增长、摘要和缓存条件的敏感性，并在不同任务或留出数据上验证。

## 敏感性检查

同一增长序列截取 40、80、134 次调用，分别设置 5%、11%、20% 摘要保留，以及始终暖缓存／每八次调用模拟一次缓存过期，共 18 组。过期位置是人为指定的共同调用序号，并非根据真实时钟或服务商缓存推断。摘要输入费用比例不随该模拟缓存条件变化，仍是简化假设；两策略得到同一失效序列，但不同策略的真实时序未必如此。

研究策略在 18 组均未识别出可用模型、与固定 60% 成本相同。额外的固定 50% 仅是测试对照，不是 FoldPoint 候选：例如暖缓存、保留 20%、80 次调用时，固定 50% 多摘要一次，费用约 1.0463 对固定 60% 的 0.9627；暖缓存、保留 11%、134 次时，固定 50% 约 1.5088 对 1.5074。由此只能说明提前摘要在这些假设下可能受结束位置和摘要次数影响，不能推导某个固定阈值对真实任务最优。
