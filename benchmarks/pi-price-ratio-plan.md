# DeepSeek 执行、价格比例变化：Pi 插件先导试验

本试验只改变模型的**计费元数据**，不更换执行模型。Pi、FoldPoint、任务、
原生压缩器、受控上下文窗口及缓存预热配置保持一致；所有请求仍发给
`deepseek-flash`。因此报告中的假设费用不是 provider 账单，更不是 Claude 实测。

## 预先固定的价格情景

单位是每百万 token 的假设费用（`HYPOTHETICAL`），不是报价：

| 情景 | 输入 | 输出 | 缓存读 | 缓存写 | 想检验的问题 |
| --- | ---: | ---: | ---: | ---: | --- |
| `native` | Pi 模型表 | Pi 模型表 | Pi 模型表 | Pi 模型表 | 真实 DeepSeek 计费基线 |
| `cache-read-60` | 1 | 5 | 0.6 | 1.25 | 缓存读取较贵时是否更值得压缩 |
| `cache-write-200` | 1 | 5 | 0.1 | 2 | 压缩后重建缓存较贵时是否应延后压缩 |

情景值通过 Pi 的 `models.json` 中 `deepseek/deepseek-flash.modelOverrides.cost`
写入每个独立实验目录。FoldPoint 从 Pi 的同一有效模型价格做决策，轨迹记录
相同的价格快照，分析器用该快照计算假设费用。所有比较组都使用同一情景。
假设情景仅允许 `deepseek-flash`、`cacheWarming: off`；否则缓存预热费用仍由
Pi 按真实价格上报，混用货币会造成错误结论。生产插件没有开启情景的默认值。

## 顺序与判定门

1. 零付费单测与 Pi `--list-models` 预检：价格、货币标签、任务质量门和轨迹
   配对正确。失败即停。
2. 先导：`cache-read-60` 情景的一个仓库修复任务，各跑 Pi 默认、FoldPoint
   否决、固定晚阈值一轮。此阶段只验证执行路径和报告。预算由三次任务运行
   与单次 300 秒超时限定，不以假设费用充当真实 API 预算。
3. 若通过，再对三个情景、至少三个不同任务做多轮对照，轮换执行顺序。
   26K 压力窗口与正常窗口分别报告；短任务作为零压缩负对照。

质量失败、轨迹不完整、未定价失败压缩，均不得算为费用胜利。主要结果是
每个情景下 FoldPoint 相比 Pi 默认的完整可计费配对胜率与总费用；固定晚阈值
是必须保留的强基线。零压缩配对单独计数。单轮先导不用于“多数情况下省钱”
或“在 Claude 上有效”的宣传。

PowerShell 下逗号列表须作为一个字符串传给 `npx`，例如：

```powershell
npx tsx tools/pi-paired-run.ts --tasks pricing-regression `
  --conditions 'default,veto,late' --reps 1 `
  --price-scenario cache-read-60 --cache-warming off --out $outPrefix
```

## 先导结果：`cache-read-60`，一轮

2026-09-25 在本地 Pi 0.87.0 bundle、DeepSeek `deepseek-flash`、独立 26K
窗口配置下运行三个策略，每个策略一轮。预检通过；三个独立工作区的仓库
修复任务都通过外部质量门，轨迹均有 `session_end`，且决策记录的价格快照
确为 `HYPOTHETICAL` 的 `1 / 5 / 0.6 / 1.25`。这次执行调用了 DeepSeek，
表中费用则按假设价格重算，**不是实际支付金额**。

| 策略 | 普通调用 | 普通请求 prompt token | 成功压缩 | 未定价失败 | 否决 | 已观测假设费用 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Pi 默认 | 17 | 135,942 | 3 | 4 | 0 | 0.181530 |
| FoldPoint | 22 | 208,222 | 1 | 0 | 15 | 0.178218 |
| 固定晚阈值 | 18 | 156,969 | 1 | 0 | 0 | 0.143837 |

Pi 默认组的 4 次失败压缩缺用量，其费用仅为下界，不能与 FoldPoint 作
严格费用比较。FoldPoint 对固定晚阈值的配对账目完整，但单轮中其假设费用
高约 **23.9%**，普通调用多 4 次，prompt token 也更多。此结果是对
“动态策略在较贵缓存读取下自然更省”的一个**负面先导信号**，不是稳定劣势
的证明；模型解题路径并未保持一致。不能通过事后改变任务或阈值把这轮改写为
胜利。下一步先扩大任务类型和重复数，同时继续保留负面结果与未定价门禁。
