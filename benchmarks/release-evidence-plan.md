# 发布前最小证据计划

目前不能声称 FoldPoint 在多数真实任务下优于 Pi 或固定60%。真实 DeepSeek 开发任务中，
新周期组 USD 1.522145052，历史固定60% USD 1.500053412；前者高1.47%，且两组跨批次。
72格合成测试中仅既有宽跨度历史组的费用合计低7.73%，不能当作真实或冷启动收益。

## 先打通被测版本

1. 在真实本地Pi RPC子进程、回环provider下，连接 learned-shadow 桥接，按真实事件顺序
   评估、接收成功摘要即时结果、同步落日志。重启进程后重载，验证绑定、序号和建议。
   另测截断日志、重复事件、存储失败，以及扩展未加载时的行为。全程不触发付费请求。
2. 明确实际控制策略及其冷启动回退；当前桥接仅影子观察，不改变Pi压缩，不能拿它声称节费。
   若没有经过验证的主动控制入口，先完成入口，再冻结commit、配置、任务和评分规则。

## 最小真实对照

- 使用至少两个不同、未用于参数调优的任务；其中一个需要多次摘要，另一个采用中等长度。
- 同一任务分别运行Pi原生、固定60%和明确版本的FoldPoint；若预算不足，优先同批次固定60%对照。
- 各组隔离缓存命名空间，记录缓存冷暖与开始时间，避免相互预热；同任务尽量交错运行顺序。
- 按成功、失败、摘要、重试、预热分别记录全部调用用量和成本；显式标识缺失计费。
- 预先定义任务通过标准，记录准确性、完成率、摘要次数、总费用和耗时；不能只比较token。
- 每组报告完整数据，失败或提前结束不得当成零成本；不完整结果不能参与节费胜负统计。
- 先做低成本单阶段连通检查，再给每组设置费用停止线；停止线按阶段检查可能被单阶段超出。

结果只支持所测任务和模型配置。两项任务即使都省钱，也不足以证明“多数真实任务”省钱；
要提出该主张，需要更多独立任务、重复运行和可复现的任务质量评估。若新模型未有足够历史，
记录回退固定60%的比例；不能把人工提供的宽跨度历史当作免费冷启动结果。
