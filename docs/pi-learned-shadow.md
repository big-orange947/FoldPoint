# Pi 即时反馈影子接口

`adapters/pi/learned-shadow.ts` 是仓库内的宿主/RPC桥接工厂，不是自动加载的Pi扩展。
已在本地真实Pi SDK会话中，以回环模拟服务验证桥接；没有付费调用。

本地Pi的 `session_compact` 事件只有compactionEntry等字段，不含即时压缩后长度。
因此不能订阅这个事件后，把下一次context长度直接当即时样本。
宿主需在成功且未中止的RPC `compaction_end.result` 可用时，显式调用 `observeImmediate`。
返回字段的真实性和压缩器/估算器版本绑定由宿主负责，不是字符串source本身能认证的。

接口顺序：

1. `createPiLearnedShadow` 通过同步 `loadHistory` 重播同一绑定、同一顺序流的完整反馈日志。
2. 请求前调用 `evaluate`，传入数值型上下文、增长、报价、账单模型和研究边界。
3. 成功摘要返回后调用 `observeImmediate(result, {sequence, stage})`。
4. `appendFeedback` 同步持久化白名单数字；`writeEvaluation` 同步记录支持范围与回退原因。

两种输出都没有正文。影子返回始终 `applied=false`、`canDrivePolicy=false`；
不注册事件、不调用compact、不返回cancel，也不能把recommendation直接当Pi事件返回值。

历史不兼容/损坏、存储失败或评估失败会禁用此实例的后续影子评估，
返回固定原因而不是回显原异常；它不应改变宿主的原生压缩或任务执行。
已学习但未成功写入的状态也会被禁用，不假装内存与磁盘一致。
回调目前仅支持同步I/O；异步宿主需自行先完成事务后再交接，不能传入fire-and-forget回调。

日志最多重播4096条，超过限制明确阻断，不静默截取末尾32条。
学习器内部仍只保留32条；完整重播用于重现漂移重置与顺序状态。
宿主需要自行规划显式日志轮换和新的流序号，不能把跨会话重置为1的序号直接拼接。
这只是有界研究实现，尚无自动持久化迁移或多进程协调。

测试验证数值反馈保存/重载后学习和建议一致、旧序号不重复写入、缺即时长度不学习、
不兼容历史不偷偷清空成冷启动，以及写入失败不再输出正常建议。
这不证明真实Pi接线、磁盘崩溃一致性、性能或节费。

本地SDK探针完成两次真实 `session.compact()` 生命周期：每次摘要前做影子评估、
成功返回后传入即时结果，并重建桥接实例重放内存日志；两次重载状态与原实例一致。
共6次普通请求、2次成功摘要，服务请求只到回环模拟服务，零外部调用，建议未执行。
这是SDK会话和桥接实例重载，不是RPC进程重启、磁盘持久化或真实provider验证。
下一步需要验证RPC进程重启和真实持久化，再考虑实际宿主的观察模式。

## 单写入者研究日志

仓库内 `tools/pi-shadow-journal.ts` 提供同步 JSONL 文件适配器，可作为上述桥接的 `loadHistory` 和 `appendFeedback`。新文件使用独占创建，记录绑定模型、压缩器、估算器与误差假设；每条反馈只写白名单字段，并在返回前调用 fsync。重新打开时拒绝不匹配配置、非法 UTF-8 和不完整的末行。测试通过独立 Node 进程重新加载反馈并重现学习状态。

这仍是研究工具，默认 Pi 扩展没有启用；必须由宿主确保同一文件只有一个写入者。文件大小检查仅能发现部分外部修改，不能代替进程锁或事务。文件损坏或持久化失败时停用该观察实例，不能自行清空历史继续。尚未证明机器断电一致性、真实 Pi RPC 重启或节费效果。

本地 Pi SDK 回环探针现已将两次真实 `session.compact()` 的即时返回接入此文件日志：每次保存后关闭并重新打开文件，重放得到的学习状态与保存前一致；日志检查未包含测试提示词或密钥。服务仍是模拟回环，Pi SDK 所在进程没有重启，因此这不是 Pi RPC 重启验证。

进一步的 `tools/pi-shadow-rpc-probe.ts` 启动两个独立 Pi RPC 子进程：首个进程调用模拟模型并通过 RPC `compact` 返回实际结果，宿主同步记录反馈；关闭该进程和日志后，宿主重开日志、重建观察器，再启动第二个 Pi 进程并完成一次普通调用。回环服务本次观察到一次摘要操作包含两次请求，费用实验应统计所有请求。子进程使用隔离配置和仅允许回环 fetch 的防护，未调用付费服务。

第二个 Pi 进程使用新会话，重启的是 Pi 子进程，宿主本身没有重启；独立宿主进程重载仅由日志单元测试另行验证。该实验未恢复 Pi 会话上下文，也未证明网络断连或机器断电后的恢复，更没有对真实策略或任务质量作评估。

增强回环还验证了冷启动回退、重载前后相同输入产生相同影子评估，以及第二个进程的新摘要按后续序号追加；重复序号不会再次学习。此次两次摘要共四次模型请求，均为本地模拟请求。影子决策仍不接管 Pi 压缩。
