# 近似反馈研究路径

目标是利用来源明确但不精确的宿主估计，不能将它冒充 provider 实测保留率。
本实现只在 `tools/` 的旁路研究代码中使用，未导出为公共 SDK，也未改默认核心或 Pi 策略。
没有新的模型调用，更新最多扫描最近 32 个数值样本，没有正文输入或网络依赖。

## 数据与范围

每条观测必须显式提供 before/after 的名义长度、各自绝对误差预算、来源和配置标识。
误差预算是宿主假设，**不是从一次观测推出来的真实误差率**。即时估计和延后估计会分别计数。
延后估计必须额外提供同单位的新增上下文范围；没有增长信息时暂不学习。
provider 完整 prompt 的用量不能自动标记为宿主估计单位。

令 before 为 B、after 为 A，误差预算为 eB/eA，新增内容在 [gL,gU]：

```
lower ratio = max(0, A - eA - gU) / (B + eB)
upper ratio = (A + eA - gL) / (B - eB)
nominal ratio = max(0, A - midpoint(gL,gU)) / B
```

必须保证 B-eB>0。增长下限比 after 的可能上限还大时拒绝该观测。
没有提供增长的即时观测按零增长处理，宿主须保证这条语义成立。

后续样本通过 EMA 更新名义比例；研究参数 alpha 默认 0.25。
相对范围越宽，更新影响越小：`influence = 1/(1+(upper-lower)/max(nominal,epsilon))`，
实际更新系数为 `alpha*influence`。冷启动没有额外先验，第一个样本保留其完整范围，
因此单一样本的 influence 不会凭空赋予它准确性。

输出范围覆盖最近 32 个输入区间及 EMA 剩余历史影响，反映近期差异；
这不是未来覆盖保证或统计置信区间。扩大误差假设不会改变一条样本的名义点估计。
对新 before 做比例投影，超出已观测 before 范围会标为 `extrapolated`。
不强行把比例裁到 100%：观测到不缩短甚至膨胀时，应如实反映。

## 边界与接线

- `exactSamples` 始终为 0，`canDrivePolicy` 始终为 false。
- 配置标识由宿主负责包含模型、压缩器和估计器版本；不兼容输入不改变状态。
- 单个 tracker 接收一个有序兼容流。合法观测的 sequence 单调递增，失败或暂不学习的
  记录也会消耗序号；同一条记录不能稍后悄悄换数据重放，重复/乱序输入不重复学习。
- 数字非法或溢出时抛错且不改变状态；失败压缩不更新比例。费用仍由原有账本统计。
- 这是比例 EMA，不替代精确 affine 模型；保留底座、跨尺寸变化和任务阶段漂移仍可能误导。

离线敏感性报告：

```powershell
npm run verify:approximate-feedback
```

原生 Pi SDK 默认采集不变；显式开启近似旁路：

```powershell
npm run capture:pi-feedback -- --out traces/pi-approx-offline-NEW --approx-error-fraction 0.1
```

这个 0.1 只是演示性的误差假设，不是推荐默认值或已校准误差。参数必须位于 [0,1)，
工具分别向上取整为 before/after 绝对预算。若取整后 before 下界非正，则报告近似模型不可用，
不使本来成功的采集失败。不开参数时不会创建近似模型；需要真实请求仍须另外显式 `--live`。
配置标识由模型、Pi 版本、摘要上限和保留设置等公开元数据生成，报告中不记录正文。

已有一次真实 Pi 采集仅作离线回放：1474 的即时长度估计可以成为一个近似观测，
但不能证明下次预测准确；1518 的后续 provider 输入并不是它的真值标签。
0%/10%/25% 是三种独立敏感性分支，每支只读同一观测一次，不冒充三份真实样本。
8 项检查和原生 SDK 离线测试验证的是这些契约，不是收益或质量结论。

## 连续预测检查

`npm run verify:feedback-prediction` 固定既有 tracker 源码指纹，运行 9 类合成情形 × 3 个
seed × 40 次尝试。四个对照都先保存当前预测，再生成当前结果；后续只接收宿主可见反馈。
固定 10%、上次比例、普通 EMA 与近似 EMA 使用相同成功评分分母，冷启动也不能删掉。
未知增长时所有学习对照不训练，但预测仍评分。失败尝试不训练、不当成功压缩结果评分。

主指标是平均绝对误差 MAE（tokens）；另有相对误差和统一排除前三次成功尝试的 warm MAE。
范围覆盖率同时公开分母和范围宽度。`--details` 输出逐步 JSON 供复查；默认只输出汇总。

当前结果揭示：比例 EMA 对固定底座不合适，对阶段突变的响应又因误差降权而偏慢。
范围即便覆盖真值，也不能证明误差假设正确或名义预测有用。后续如改模型，应新建比较，
不能静默替换本基线的源码指纹、输入或数字。详见 [本轮报告](../benchmarks/feedback-prequential.md)。
